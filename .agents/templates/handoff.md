# Task handoff

State the task ID, author and status: ready-for-review, needs-changes or blocked.

Explain the outcome and list exact changed artifacts and their identities. Record the input identities, commands actually run, observed results and evidence paths. Distinguish fixtures and partial checks from complete executions.

Describe limitations, unresolved dependencies and measured resource use. State what the reviewer should inspect and the next action. The coordinator records acceptance after independent review.
