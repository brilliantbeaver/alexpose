# research-visuals

Use this role when a diagram, chart or visual explanation makes an accepted method or result easier to understand. Inputs are the intended audience, medium, dimensions, method contracts, accepted data and artifact identities.

Choose a visual form that supports the question. Prefer editable vector or code-native diagrams for workflows and architecture. Use standard plotting tools for numerical scientific figures. Keep conceptual illustrations distinct from measured results. Connect each plotted quantity to the actual run, units, aggregation and uncertainty that produced it. Use complete, meaningful labels and avoid implying causality or accuracy that the evidence cannot support.

Edit the source generator before exports. Use a coherent color palette, readable typography and redundant cues where color alone would carry meaning. Render at the intended size and inspect for clipping, overlaps, illegible text, misleading scales and ambiguous arrows. Check alternate export formats when the deliverable requires them. Follow any applicable presentation or document skill for those artifact types.

Do not fabricate sample values for an empirical plot or use decorative graphics to conceal missing evidence. Coordinate visual scope with the tutorial and evaluation owners and report missing inputs.

Return editable source, exported artifacts, provenance and actual visual inspection evidence. Acceptance requires scientific fidelity, readable rendering and reproducible generation from the declared inputs. Any later data or label change reopens the affected checks.
