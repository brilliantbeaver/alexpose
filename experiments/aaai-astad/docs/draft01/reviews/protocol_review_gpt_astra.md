# Adversarial scientific review of the implemented context study

Reviewer: GPT-6 Astra. Date: November 15, 2026. This is a static implementation and protocol review before the expanded real-data results were supplied. I did not train a model, inspect new outcome tables, download media, or change study code. Proposed explanations and future outcomes below are hypotheses, not new measured results. Line references identify the files as reviewed on this date.

The implementation supports a defensible exploratory study of a model-dependent predictive-benefit score. It does not yet establish a successful detector, a biological coordination measure, a JEPA advantage, or an independently confirmed result. I found no direct source-role overlap or prohibited contextual-feature sharing in the principal neural path. The most consequential remaining problems concern the comparison that identifies the contribution, limited normal support, historical selection, and the gap between development diagnostics and mechanism evidence.

## High severity: the primary contrast does not identify the benefit subtraction

**Evidence.** [predictive_profile.py:309](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/predictive_profile.py:309) and [predictive_profile.py:335](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/predictive_profile.py:335) construct a two-sided, region-standardized reference distance. [study_runner.py:191](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/study_runner.py:191) already fits matched benefit, own, full, and patch references. However, the only automatically reported paired interval is benefit distance versus raw full KL, at [study_runner.py:318](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/study_runner.py:318).

A positive primary result could arise from two-sided reference calibration, preserving three regions, or variance scaling, without an advantage from subtracting own-joint error. Identical joints and support remove other confounders but do not remove these changes. The existing constituent-distance controls are therefore essential evidence, not optional supplementary ablations.

**Action.** Preserve the declared primary comparison. Before writing a benefit-specific headline, report paired source-level contrasts against both `full_distance` and `own_distance`, on the same cohort, with the same conditional uncertainty procedure. Clearly label these as supporting contrasts and disclose their multiplicity. If the benefit profile only beats raw KL, claim improvement over that particular raw score. Do not claim that cross-joint benefit is the ingredient responsible. A score constructed by subtracting two losses can still be dominated by one constituent.

## High severity: historical cohort reuse prevents confirmatory or fresh-test language

**Evidence.** [study_data.py:40](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/study_data.py:40) through line 44 derive historical exposure from one earlier retained-window index. [study_data.py:63](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/study_data.py:63) labels other sources `not_in_previous_study`. The draft00 background records the previously explored 91-source cohort and explicitly acknowledges design changes after its results were inspected. The expanded normal count and final role counts have not been established in this review.

Membership outside that one index is not proof of no prior inspection, extraction, exploratory analysis, or related selection. New outer folds prevent fitting on their own held-out source IDs, but cannot undo analyst adaptation to an earlier version of the same population. Most available normals are historical. Extra abnormal folders do not create an independently sequestered binary test population.

**Action.** Put this limitation in the main methods and abstract-level qualification, not only an appendix: “exploratory internal source-held-out evaluation on a cohort that overlaps earlier development.” Report historical and newly scored source counts separately by normal/abnormal status. Describe `not_in_previous_study` literally as absence from the specified index. Freeze the complete run before examining scores, retain adverse runs, and record any subsequent design change. A newly scored abnormal-source subgroup is useful evidence, but its comparisons against reused normals are not an independent replication.

## High severity: the bootstrap cannot support a broad negative result or full uncertainty claim

**Evidence.** The reference mean and three variances are estimated from five sources using fixed shrinkage at [predictive_profile.py:309](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/predictive_profile.py:309). Leave-one-reference-out changes only reference parameters at [predictive_profile.py:350](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/predictive_profile.py:350). The bootstrap at [predictive_profile.py:435](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/predictive_profile.py:435) fixes fitted weights, reference parameters, assignments, and observed source identities. The normal-count-weighted within-fold AUROC is implemented consistently with that stated estimand.

Five reference observations are not five precise estimates merely because each contains many windows. Shrinkage stabilizes a denominator but does not remove reference-mean uncertainty. If roughly two dozen normals survive, each test fold will contain only several normal ranking units. Hundreds of abnormal sources cannot replace missing normal diversity. Cross-fold fitting also reuses normals in other folds' learning/reference roles; the reported interval does not propagate this fitting dependence.

**Action.** Publish actual train/reference/test normal counts, reference-removal score/ranking changes, and fold-specific AUROCs alongside the conditional interval. Keep “conditional on these fitted models and references” next to the interval wherever used. Use the predeclared 0.05 target carefully: an upper conditional bound below 0.05 only excludes that improvement conditional on this fitted analysis, not for the method under new training samples. A wide interval is inconclusive. If reference omission reverses the substantive conclusion, make reference instability a result rather than averaging it away. An initialization replication, if completed without choosing the favorable run, addresses a different uncertainty from these sensitivities.

## High severity: latent predictive help is not a measure of local movement dependence

**Evidence.** [context_prediction.py:158](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/context_prediction.py:158) through line 164 generate the latent answer using the complete-input contextual teacher. The restricted predictors are correctly re-encoded before attention at [context_prediction.py:97](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/context_prediction.py:97), but the frozen backbone was learned under a different context distribution. Separate heads at [context_prediction.py:145](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/context_prediction.py:145) share initialization, not fitted parameters or identical effective representations. Shared normalization uses pelvis and torso observations in [data.py:373](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/data.py:373).

The full branch can help predict information that the teacher put into the target from other joints. That is intended contextual prediction, not a hidden-target leakage bug. Separately optimized finite predictors also need not achieve the Bayes risks required to identify conditional information. Own-joint performance may deteriorate because a frozen broadly trained encoder is evaluated with very few keys. Neither a positive nor negative loss difference is a causal or model-independent measure of coupling.

**Action.** Use “predictive benefit for these fitted models under the declared body reference.” Show normal-source coordinate own/patch/full losses before interpreting abnormal discrimination. Require the coordinate control and matched patch-local comparison to support a movement-relationship claim. Report `loss_patch - loss_full`, available from the saved support tables, if claiming useful cross-time information beyond the target four-frame interval. A patch contains motion as well as geometry. If only latent scores succeed, the conclusion concerns contextual representation scoring until the alternative explanation is resolved.

## High severity: the present interventions are development diagnostics, not held-out mechanism validation

**Evidence.** [run_study_controls.py:93](/Users/pmui/dev/alexpose/experiments/aaai/scripts/run_study_controls.py:93) restricts intervention observations to normal fitting sources. Lines 100 through 105 select their first eligible long window and enforce that training-source restriction. The protocol's example uses fold 0. [teacher_decomposition.py:145](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/teacher_decomposition.py:145) implements a correct four-value algebraic decomposition; [run_study_controls.py:140](/Users/pmui/dev/alexpose/experiments/aaai/scripts/run_study_controls.py:140) restricts it to eight unchanged-coordinate joints.

A response on these observations shows software sensitivity in an already fitted population. It does not establish sensitivity on unseen normal sources. The four-term identity is algebraically necessary and cannot itself validate an explanatory mechanism. A nonzero contextual-teacher term is also expected in principle from a contextual encoder. One four-frame shift and one noise/dropout magnitude do not establish that timing sensitivity exceeds measurement sensitivity generally.

**Action.** Label the existing outputs “development sensitivity diagnostics.” If they become the manuscript's main explanation, freeze the edit and selection rules and evaluate them on the appropriate outer-held-out normal sources, using each source's fitted outer model, without adapting to the outcome. Otherwise keep the weaker claim. Report source-level paired changes, attrition, geometry diagnostics, and the whole-body and observation-damage controls. For the alternative teacher-effect paper, require a reproducible, consequential change in a ranking or anomaly conclusion, not merely a nonzero decomposition component. The current eight-joint raw-KL decomposition cannot explain additive contributions to the nonlinear three-region profile score; the implementation appropriately says so.

## High severity for a method-superiority claim: the ridge comparison is a limited fixed baseline

**Evidence.** [linear_context.py:44](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/linear_context.py:44) fixes 256 sampled windows/masks and alpha 10. Separate regressions are fit for every joint/time/branch at line 63. [linear_context.py:31](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/linear_context.py:31) produces 1,024 coordinate features plus 128 availability indicators. With half the tokens requested, each target regression uses only a subset of those 256 draws. The runner's eight-example floor at [study_runner.py:101](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/study_runner.py:101) verifies existence, not adequate estimation. Neural heads have a different sample budget and share parameters across joint/time queries.

The comparison is information-matched at scoring, but not an optimization-equated contest. A failure of this ridge setting would not establish that nonlinear or JEPA representations are necessary. Conversely, strong ridge performance would directly weaken a representation-learning claim. Random latent targets also differ from trained latent targets, so trained versus random latent AUROCs do not isolate representation learning with a fixed estimand.

**Action.** Call this a “fixed source-balanced ridge control.” Show its held-out normal coordinate errors and target-specific training support. For a strong superiority claim, demonstrate adequacy with normal-only training-budget/regularization sensitivity or a validated published baseline, without choosing settings on abnormal outcomes. If that cannot be completed, narrow the claim to the tested settings. Interpret trained versus random coordinates, which have common observable targets, alongside the latent comparison. Do not substitute the separately supervised five-class RF for a normal-only anomaly baseline.

## High severity: adequate normal learning remains a prerequisite, including for a null result

**Evidence.** The study uses fixed update counts, and the protocol explicitly says they do not establish convergence. While this review was being finalized, the coordinating investigator reported that normal-validation coordinate full-context MSE remained worse than own-context MSE in all four folds after 512 head updates. I have not independently checked those artifacts, and this is not a new measured result produced by this review. The investigator stated that a fixed 4,096-head-update sensitivity, retaining 512 pretraining updates, was being launched before abnormal test-result inspection; the original 512-head result remains primary.

This reported diagnostic is consequential. Before successful normal predictive benefit is demonstrated, failure of an abnormal benefit score can reflect predictor estimation, optimization, or the frozen encoder's context mismatch. It cannot establish that gait relationships lack anomaly information. Conversely, the longer run does not automatically validate the biological interpretation or guarantee useful detection.

**Action.** Preserve both runs and timestamp the rationale for the longer schedule. Label 4,096 updates a normal-diagnostic-motivated sensitivity, not the originally fixed primary. Show matched own/patch/full normal-coordinate learning curves and source-level normal benefit for both schedules. Do not choose the manuscript's detector or headline according to which test result is favorable. If the intended predictive ordering is still absent, center the report on the limitation of these fitted predictors and keep claims about coupling or a well-powered negative result out.

## Medium severity: four selected patches do not equalize effective observation precision

**Evidence.** [predictive_profile.py:199](/Users/pmui/dev/alexpose/experiments/aaai/aaai_gait/predictive_profile.py:199) through line 211 select four target identities. Lines 228 through 234 still average mask exposures within each window, windows within each sequence, and sequences within a source. A selected patch can appear under several overlapping window contexts and different mask exposures. Distinct-support keys include `sequence_id` at line 213.

This is a useful matched target-budget sensitivity, but it does not equalize the amount of context, repeated exposure, temporal coverage, or estimator precision across sources. The support count deduplicates overlapping windows inside a sequence, not duplicate physical observations assigned different sequence IDs. Cross-sequence duplication is an audit question, not an observed defect established by this review.

**Action.** Report the saved exposure counts, sequence counts, and time spans for the four-patch analysis. Say “four distinct annotated target patches per joint,” not “equal information” or “equal precision.” Audit same-source overlapping annotation intervals and duplicate/reposted people where feasible. Do not infer independent participants from either sequence or source IDs. If duplicate physical intervals exist, disclose how they are counted rather than silently treating annotation identity as physical independence.

## Necessary novelty and manuscript boundary

The candidate contribution is a controlled empirical finding about subtracting restricted-context prediction losses and comparing their regional normal-reference profile. It is not a new skeleton JEPA, a discovery that joints are dependent, or a neuromusculoskeletal world model. [S-JEPA](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/04755.pdf) explicitly uses contextual skeleton targets. [SeeKer](https://arxiv.org/abs/2506.18368) already uses conditional keypoint prediction for anomaly scoring. [GenGait](https://arxiv.org/abs/2604.01997) already studies normal-only masked gait reconstruction and joint inconsistency. [Beyond Marginals](https://arxiv.org/abs/2509.15033) explicitly separates marginal, temporal, and inter-variable behavior in anomaly detection. These primary sources were checked for this review; they preclude broad priority claims but do not by themselves decide the narrower experiment's value.

A strong positive manuscript needs a measured gain over the matched constituent distances, adequate held-out normal prediction, a local-target result that supports the intended interpretation, and completed controls whose scope is accurately stated. A strong alternative explanation needs a consequential and reproducible target-context effect. An inconclusive or adverse run should yield a plainly bounded exploratory report, not a strong-method claim obtained by switching score, category, split, or narrative after inspection.

Until results are available, the defensible contribution sentence is: “We implement and evaluate a matched-context diagnostic for normal-only gait anomaly ranking, with explicit controls for target contextualization, constituent prediction errors, reference estimation, and observation support.” Replace “evaluate” with completed numerical findings only after the real run and all claimed controls have been verified.

Coordination note: before this review was completed, the investigator accepted the need to add paired supporting intervals against the already recorded constituent-distance and representation controls, and to describe training-normal interventions as fitted-model sensitivity. Those planned responses are not verified implementation changes in this review.
