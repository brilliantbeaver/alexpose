# Working decision for the next iteration

This is an instruction-design task, not a new efficacy experiment. The canonical instructions will be `notes/aaai/05-iterate-02-INSTR.md`. The completed draft01 manuscript, model artifacts and 12 executed notebooks remain the evidence baseline. New coverage counts are read-only availability probes, not new performance results.

The preferred experiment measures whether the other leg adds useful prediction beyond the target leg's own visible movement. Use observable normalized coordinates and a small retained-baseline residual predictor. Preserve a separate amplitude/posture/raw-time channel, because neurological and muscular abnormalities need not reduce cross-leg dependence. Own-joint to own-leg prediction is a geometry control. The primary information increment compares the capacity-matched own-leg correction with the both-leg correction, sharing the same frozen base and target. Arm/trunk context is optional and never required for lower-limb coverage.

The full input and uniform masking allowlist stays at 16 BlazePose indices 11–16 and 23–32. A new lower-limb readout uses 25–32 only. Read-only availability suggests 304 sources, including 28 normal, 9,442 windows and 1,381 sequences; focal normal/PD/stroke/CP/myopathic counts are 28/10/15/10/27, or 90 unique sources. The five extra normals were excluded solely by arm support, and all 28 normal sources were used in previous exploration. They are not independent new validation. Never overwrite the historical 251-source primary.

Use 32-frame windows for the main new method. At 15 Hz their first-to-last span is 31/15 = 2.07 seconds. A long-window requirement is damaging: 96-frame observation QC retains only 12 normal sources, 128 only 9, before profile gating. Phase, cadence and stride-variability claims require separate reliability checks. Never condition on phase computed from hidden targets. No independent per-leg phase alignment, per-clip amplitude standardization, or trunk-uprighting that erases phenotype.

First prove predictor adequacy on a known-dependency synthetic fixture and source-held-out normal development, with a frozen local-leg baseline plus a zero-option residual correction. A zero residual preserves the exact baseline prediction. Training/selection containment is not a guarantee of better held-out risk. Measure baseline error/headroom so an almost-solved local completion problem is not mislabeled undertraining. Use inner fitting-normal source folds for hyperparameters and residual gating, separate from the five normal-reference sources and outer tests. Keep uniform masking as the reference and add the declared matched-probability J/A alternatives, all independent of motion. Any contiguous-gap diagnostic is an evaluation-only sensitivity, not the new training sampler.

For a mechanism-sensitive diagnostic, hold the target and target-leg history fixed and replay the other leg from finite offsets such as ±4 frames in an audited longer parent segment. No circular wrap. Use a common target/key-validity set, fixed normalization anchors, and donor availability/mask accounting. Shift permitted donor distal-joint vectors relative to a visible donor hip, and attach them to the permitted original opposite hip. Keep hip support explicit; the edited input is not a fabricated clinical body. These are timing controls, not physical interventions. They do not exactly preserve window marginals; quantify marginal and observation drift and use a matched temporal-crop control, which changes the target and therefore answers a different question. Do not call their ranks causal effects or p-values. Phase-resolved curves are optional after the sequence/cycle gate.

The new contribution would need a demonstrated dissociation: a coordinate/context measure responds to altered relative timing under valid controls and adds value beyond marginal motion, phase/cross-correlation, calibrated constituent errors, random features, and a credible published baseline. None of these improvements is currently measured. GenGait, FSGait, SeeKer, Beyond Marginals, Q-PCI and linear intersegmental asymmetry already constrain novelty. Larger JEPA models or stochastic latent variables are not the critical path.

The new exploratory primary endpoint is normal versus the four named abnormal families. Use all 12 folders for coverage and a required broad non-normal secondary endpoint with the same frozen scores. This outcome-informed redesign does not replace the historical all-folder primary and is not confirmatory. Keep the supervised five-class RF/probe task separate. Preserve ordinary abnormal-category wording, not confirmed diagnosis. Report activity/camera confounds, source-level attrition and unknown participant dependence. Do not choose the endpoint, architecture, sign or training budget for favorable new test scores.

Design notebooks 12–17: data/coverage and video context; positive controls and nested prediction; matched context timing probes; marginal/relational scores and normal references; matched baselines and source-level evaluation; final evidence, failure analysis and manuscript decision.
