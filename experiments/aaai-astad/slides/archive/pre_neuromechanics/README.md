# Tutorial slides

Open [index.html](index.html) in a browser. The 16-slide deck works offline, uses editable SVG figures, and includes expandable speaker notes. Use arrow keys to advance. Print in landscape to save a PDF. The Markdown source is [tutorial.md](tutorial.md).

Rebuild the deck and figures with `uv run python scripts/make_visuals.py` from `experiments/aaai`. All factual claims link back to the experiment [literature review](../docs/literature_review.md) and [data audit](../docs/data_audit.md). Counts describe annotations, not successfully extracted videos. No charts show fabricated training results.
