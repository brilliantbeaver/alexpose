# Teaching and results slides

Open `tutorial.html` in a browser. Its 20 pages pair teaching steps and completed results with editable SVG diagrams. Print to PDF with landscape pages if desired. Source: `../scripts/build_visuals.py`. Run `scripts/analyze_research.py` and `scripts/build_results_supplement.py` after the joint test release to regenerate the result figures, then rebuild this deck. The first fourteen pages teach the method; the final six summarize released evidence and endpoint tables. See `../docs/results_tables.md` for all secondary scores and uncertainty.
