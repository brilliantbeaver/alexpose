# Revision implementation notes

These notes clarify the frozen protocol without changing models, cohorts, splits or metrics.

The `prefix_mean_confidence` and `future_mean_confidence` columns average all sixteen selected-joint confidence values. Missing detections and person-gate rejection contribute zeros. They are not averages conditional on a joint passing the observation threshold. “Prefix confidence” therefore means confidence available from the observed prefix, including detection failures. It is a past-only acquisition feature. The future counterpart is used only in a separately labeled retrospective audit.

The extended cohort's post-extraction runtime record supplies MediaPipe, imported OpenCV, both installed OpenCV distributions, NumPy, pandas and Python versions. Package versions did not change during the extraction. Source, CSV, model, original adapter, extended adapter and reused-pose hashes are recorded separately. A bounding-box containment check reduces obvious person mismatches but does not verify identity when people overlap.

The earlier `binary-development-v1` experiment is preserved. `binary-development-v2` repeats the same candidate grid and validation selection with stronger provenance, an explicit mixed-probe primary comparator, and planned direct-versus-five-class-derived paired comparisons. No final test metric was inspected to make this revision.

`binary-development-v3` is the final provenance seal. It retains the same training grid and validation selections as v2 and sets the final paired bootstrap budget to the protocol's 2,000 replicates. This reporting correction is made before any final test metric is released. All overlapping binary and forecast decisions will be frozen before either test report is opened.

Before final test release, a secondary anomaly audit is fixed as follows. For every arm and seed, report source-level AUROC and average precision for raw forecast MSE, energy score, and excess MSE defined as model MSE minus matched persistence MSE. Higher values always indicate more abnormal motion. Report every score and the predeclared mean-across-seed scores; select no score, direction or arm from test performance. Use identical source IDs and valid target support, and 2,000 paired source bootstrap replicates for intervals. Energy has root-distance units and is never subtracted from MSE. Quality-only classifiers use abnormal training labels while the predictive models train only on normal motion, so that comparison is a descriptive confound audit with different learning regimes.

## One fixed objective-weight audit before test release

The original three-seed validation criterion failed: deterministic residual prediction was slightly worse than persistence in all three seeds. A separate training-only diagnosis used three fixed schedule batches at each seed's final residual checkpoint. Coordinate-loss gradients on shared encoder/predictor parameters were 0.22–1.69% of the combined auxiliary-gradient norm, with a median of 0.77%. Coordinate heads were nonzero and training errors improved modestly, so this is not evidence of dead learning. Small coordinate gradients can also reflect local fitting, and Adam and gradient clipping complicate their interpretation.

This diagnosis motivates exactly one secondary sensitivity: coordinate weight 10 instead of 1 for the deterministic residual model. Reload each original pretrained state, use the identical saved 300-update source schedule and optimizer settings, and change only this loss weight. Execute all three seeds, report every result, and perform no additional weight search. Weight 1 remains the primary analysis. Weight 10 is an exploratory optimization audit and cannot replace the primary result after observing validation or test behavior. Freeze this declaration and both sets of checkpoints before the joint test release.

Two independent reviewers agreed. No patient/helper role or diagnosis was inferred from appearance. The source exclusion ledger pins the contact-sheet hash, inspected frames and reasons. The 32-frame derivative removes seven windows. Its normal training subset, normal validation subset and complete test subset retain exactly the same tensors, validity, metadata and row order. The reuse certificate records hashes and equality checks. Original forecast and objective-audit checkpoints are inherited, not described as retrained. Existing validation predictions are filtered without redrawing latent variables or temporal controls. The frozen evaluators may consume the original parent input because their final test rows are unchanged.

The 16-frame classifier cohort is rebuilt from verified raw MediaPipe pose caches and current annotation CSVs. The same pelvis-in-annotation-box gate is applied before normalization, with an eight-frame scale prefix. Both source exclusions apply before any fit. All encoders that adapt to abnormal labels, RF classifiers, supervised probes and acquisition-quality classifiers are refitted. Candidate grids, seeds and primary mixed-adaptation JEPA comparator are unchanged. Earlier classifier results are quarantined development artifacts. The clean run receives a new identity and a new joint release seal. These corrections were motivated by visual data validity, before inspecting final test metrics.

The clean classifier refit keeps the original five-epoch rule and seed 27. The implementation computes its per-stage update count from the retained normal training windows. Consequently, the cleaned cohort uses 60 updates per stage, compared with 95 in the earlier unreviewed cohort. Within the clean comparison all JEPA variants follow the declared matched-budget rules.
