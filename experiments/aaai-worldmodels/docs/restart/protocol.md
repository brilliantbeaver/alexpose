# Exploratory restart protocol: fixed-time gait dynamics audit

This protocol was declared before fitting the new full-duration cohort. Previous GAVD test outcomes were already examined, so every new comparison is exploratory. The experiment identity is `medwm-dynamics-audit-v1`. The purpose is to test necessary evidence for a gait observation transition model, not to simulate treatment or infer neurological causes.

## Data and observations

Use all media-eligible sequences in the five requested labels, preserving reference-mismatch exclusions and the two previously reviewed whole-source exclusions. Decode the existing originals under `data/videos-gavd` through the shared Ambient pose image API. Use a nominal 10 Hz grid with nearest native frames and retain actual frame numbers and timestamps. Process the entire annotated duration. Construct 24-frame windows every eight samples: 16 observed frames and eight forecast frames. No interpolation is counted as an observation. At most one identical source/native-frame tuple is retained. Overlapping annotations remain dependent and share the source fold.

Use the existing declared 16 BlazePose joints. Confidence is at least 0.5; the prefix and suffix each require at least 70% valid joints. Exclude unresolved annotation geometry at the frame gate. Pelvis centering is per frame; torso scale comes only from the observed prefix. Thus the target is relative 2D articulation, not physical velocity or whole-person displacement. The shared pelvis reference already uses both hips. Own-leg means own distal-leg articulation conditional on that shared reference, not strictly unilateral raw observation.

## Model comparisons

Each leg's target consists of knee, ankle, heel, and foot-index x/y coordinates at the next eight samples. A normal-only ridge model predicts the residual from the latest observed own-joint coordinates. Prefix values are forward-filled only from earlier observed prefix frames, retaining missingness indicators. The regression inputs use eight evenly spaced prefix positions, including both ends, to control parameter count. Per-feature scaling is fitted only to the corresponding normal training sources. Regression outputs are fit on their observed training targets; missing targets never become observed zero values.

The declared comparisons are persistence, damped constant velocity (fixed damping 0.5), own-leg history ridge, bilateral history ridge, independently trained bilateral shifted-history ridge, and static bilateral posture ridge. The shifted control first selects the same eight prefix positions as every temporal model. It circularly shifts the first seven selected opposite-leg observations by a window-specific offset in {1,2,3,4,5,6}, derived from the SHA-256 window identity, and preserves the latest opposite-leg observation. Values and validity move together, so every selected value is retained. Window-specific shifts disrupt alignment; a single global feature permutation would be absorbable by linear regression and would not be a valid control. This is an information-order perturbation, not a biological intervention. The static model repeats the latest observed pose with its known-joint indicator. Each learned arm has its own inner-validation regularization selection. Ridge strengths are 0.1, 1, 10 and 100.

## Partitions and estimation

Assign five stratified folds to source IDs with seed 2701. Every source is held out once. Fit only normal sources outside the outer fold. Select ridge strength by three-fold source-grouped inner validation on normal training sources. Average coordinate errors within a window, windows within sequence, sequences within source, and sources equally. Training weights follow the same source, sequence, window hierarchy. Outcomes from abnormal sources never select forecasting hyperparameters. Fit transforms separately inside every inner fold.

Primary outcomes are source-averaged normal forecast error over the complete 0.8-second nominal future, bilateral gain over own-leg history, and bilateral gain over the matched shifted-history model. A dynamics claim requires improvement over persistence and static posture, as well as a positive matched-control difference. Report all comparisons even when these criteria fail. The 0.4-second horizon is secondary. Differences are paired by source. Report source bootstrap intervals conditional on the fixed cross-validation fits; they do not capture training-set or patient-population uncertainty. Five overlapping training folds are not five independent replications.

Secondary abnormality rankings use raw bilateral error, excess bilateral error above persistence, and bilateral-minus-own error, with larger scores fixed to mean more abnormal. Include persistence error and prefix missingness as controls. Report source AUROC and average precision with stratified source resampling and condition-specific descriptive errors. No score reversal, outcome-selected threshold, diagnosis claim, or clinical sensitivity claim is permitted. Conditional acquisition analyses and high-confidence support are descriptive sensitivity analyses, not extra independent studies.

## Interpretation and limits

Bilateral coordination is motivated by gait physiology. Predictive dependence does not identify neural coupling, muscle synergies, disease mechanism, or intervention response. Related own/opposite-leg prediction ideas also exist in the sibling ASTAD work. The contribution pursued here is a falsifiable, fixed-time, fuller-coverage audit with matched capacity controls and complete provenance, not a claim that bilateral prediction itself is new. External patient-disjoint data, clinician-confirmed identity and labels, and treatment/action observations are required for stronger medical world-model claims.

## Prospective utility amendment before fitting

On November 16, 2026, before any new outer-fold outcomes were available, two independent specialists recommended shrinking learned residuals toward persistence to reduce variance under sparse normal-source support. For every learned arm, add a secondary forecast `anchor + beta * learned_residual`, with beta in {0, 0.25, 0.5, 1}. Jointly select ridge strength and beta in inner normal-source validation, prefer smaller beta on exact ties, and refit using the outer normal training sources. Retain the original beta-one comparisons as primary. Report selected beta values, including zero, which means persistence was chosen. This amendment pursues reliable utility without guaranteeing a positive held-out result. No new abnormal-label classifier or score-direction search is authorized by this amendment.

The full GAVD inventory was audited before outcome analysis. All 32 annotated normal sources already belong to the selected five-label scope. The seven remaining labels add 245 source IDs without cached videos and include exercise, pregnancy, style, and prosthetic walking, which are not interchangeable with the four neurological/neuromuscular annotations. Their inclusion cannot increase the normal-source support for the primary forecasting endpoint. This run therefore exhausts eligible available footage in the requested conditions. A broader label-transfer study requires a separately declared task and acquisition cohort; sample size will not be increased in response to a p-value.

## Control-design correction before fitting

Independent implementation planning identified that a globally fixed cyclic shift is an invertible feature permutation for ridge regression. Shifting before temporal subsampling also changes observed times. Before any new model outcomes, the control was corrected to window-specific cyclic shifts of the same seven selected historical opposite-leg observations, retaining the current anchor. The corrected control tests time alignment with matched observed values, missingness and model capacity. Its offset is deterministic from the window identity and cannot depend on labels or outcomes.

## Common target support and masked training loss

Before fold assignment, retain windows with at least four observed distal-joint time points per leg in the first four future samples and at least eight in all eight future samples. A target also needs at least one valid prefix observation of that joint. Apply this same gate to every method and record rejected windows. It does not use coordinate values or forecast errors. Fit each output only on its observed targets. Scale each window's hierarchical training weight by the reciprocal of its observed target-coordinate count, up to a common constant, so a window with more observed joints does not acquire more total training-loss weight. Left and right leg errors receive equal weight in the final window score.
