Full-image detection is followed by an annotation-box pelvis
gate; unresolved geometry is rejected. This gate cannot guar-
antee identity when people overlap. Coordinates are centered
on each frame’s pelvis and divided by a torso scale estimated
only from the prefix. Forecasts therefore describe relative
2D articulation, not physical velocity or clinical joint angles.

which already uses both hips.
Retention differs by annotation: 141 of 287 normal se-

The own-leg model uses target-leg history. The bilateral
model adds opposite-leg history. A separately trained shifted
model retains the same selected values, missingness, and
latest opposite-leg observation, but cyclically shifts its seven
earlier observations by a window-specific offset derived from
the window identity. This disrupts timing with matched ca-
pacity; a global feature permutation would instead be ab-
sorbable by ridge regression. The static-context model re-
peats the last observed posture as input but learns a sep-
arate future transition at each horizon. It does not repeat
a static output. Persistence and velocity extrapolation with
fixed damping 0.5 provide elementary references. Additional
inference-time shift and static perturbations are reported sep-
arately because they can create input distribution shift.
