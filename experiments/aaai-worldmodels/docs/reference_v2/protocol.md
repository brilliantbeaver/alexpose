## Locked questions and model families

1. Does a compact transition using current posture, recent velocity, and velocity dispersion improve normal-source forecasting beyond current posture and persistence?
2. Does structured prefix corruption improve a fixed compact forecaster beyond uniform corruption and an anatomy-matched random-group control?
3. Does the locked two-sided, normal-calibrated score improve within-fold abnormality ranking over negative persistence error?
4. Do the findings survive timing/observation controls and transfer to a separately sourced video cohort with participant grouping?

The primary calibrated anomaly family is fixed in advance as `ridge_posture_velocity`. This prevents selecting a main detector after inspecting abnormal labels. It uses the latest observed distal-joint positions, availability, the componentwise median of recent valid adjacent-pair velocities, their median absolute deviation, and pair support. These are image-articulation quantities, not physical speed or neural state. It predicts residual coordinates at all eight future query times. Ridge strengths are selected using normal-only inner source folds from `{0.1, 1, 10, 100}`.

The reference forecasting study includes persistence, a velocity reference using the last two observed positions per joint with fixed damping 0.5 and nominal future offsets 0.1 through 0.8 seconds, the original own-history, bilateral-history, independently fitted shifted-history, and static-posture ridge families. It adds the compact posture and posture-plus-velocity families under the same support. Existing ridge APIs are reused. Old results are not relabeled; every new fit has a new checkpoint, permitted-source membership, and implementation identity.

## Masking experiment

Use one coordinate-residual MLP with two 32-unit hidden layers, GELU nonlinearities, and a zero-initialized coordinate-output head. The zero head starts at persistence. The full-prefix input has 832 features: causal filled coordinates relative to latest observations, visibility indicators, observed anchors, availability, and measured prefix times. Use AdamW with learning rate 0.001, weight decay 0.001, gradient clipping at one, and at most sixteen distinct training-source groups per batch. Each sampled source contributes one uniformly sampled sequence and window. Save actual parameter count, time, mask counts, optimizer history, and representation diagnostics.

In each outer training pool, choose 100 or 200 updates from three inner source-fold validations of the uncorrupted M0 model with seed 27. Choose the lower normal-source MSE, breaking an exact tie toward 100 updates. Use that same duration for every policy and seed in the outer fold. Architecture, objective, target support, optimizer settings, sampled groups, and future-loss weights stay fixed. Do not choose durations from abnormal outcomes.

Run seeds 27, 41, and 73 for the following policies. The primary comparison uses the full naturally observed prefix at inference. The same deterministic corruption patterns form separate robustness tests.

| Policy | Training input |
| --- | --- |
| M0 | Complete naturally observed prefix. |
| M1 | Uniformly hide eligible prefix tokens. |
| M2 | Prioritize contiguous four-sample temporal blocks. |
| M3 | Prioritize four-sample tubes over the declared connected anatomical groups. |
| M4 | Balance low- and high-motion eligible prefix observations. |
| M3-random | Randomize anatomical-group membership while preserving group sizes, temporal extent, and the exact hidden-token budget. |
| M4-focused | Prefer larger reliable prefix motion with bounded rank weights, as a secondary motion-aware comparison. |

M1 and later policies hide 40% of eligible non-protected observations, using deterministic nearest-integer rounding. Protect every observed shoulder and hip used by normalization, plus each joint's latest observation. Natural missingness and artificial hiding remain separate. Fill causally after hiding, so removed coordinates do not survive in imputed features. Four deterministic mask banks per training window bound computation; bank choice is independently sampled at each update. Structured policies may truncate their final block to match the budget. Both motion policies reserve at least 20% of the hidden budget for uniform sampling so that unknown-motion observations remain selectable. Record realized counts and truncation.

Include one mask-pattern residual diagnostic for M4, seed 27. It receives visibility and timing features while coordinate features are erased; the common persistence anchors are added only at the output. This is a diagnostic of information in patterns, not a candidate selected for deployment. Include an untrained-encoder diagnostic with a normal-only fitted coordinate probe if feasible within the fixed core budget. Do not claim an official S-JEPA, MAMP, ASMa, or SLiM reproduction.

The main mask endpoint is normal-source MSE averaged over all eight future times after averaging predictions across the three training seeds. Also show each seed. Compare M3 with M1 and M3-random, and M4 with M1 and M4-focused. M0 has more visible training information and is an explicit anchor. Report all policies without choosing a winning anomaly direction after evaluation.

## Strict normal-only calibration

The primary detector is a reduced-training calibration ensemble, distinct from the all-training-source forecasting models. For each outer fold, partition its normal training sources into three calibration groups C. Rotate the held-out C group. Its complement R fits the forecast. No outer source or C source enters forecasting, normal-reference fitting, hyperparameter selection, or intermediate out-of-fold construction.

Within each R pool, create three source-held-out forecast predictions. Each fit selects its ridge strength using only its own permitted normal training sources. Aggregate the resulting errors to one value per R source. Fit a ridge nuisance reference `g` to log source-average forecast MSE using log prefix motion and prefix missingness. Select its strength using normal-only leave-one-source-out validation over R. Refit the forecast on all R after its own normal-only selection. Apply that same forecast and `g` to C and to the outer evaluation sources.

For each scored source, define `r = log(MSE + 1e-8) - g(log(prefix_motion + 1e-8), prefix_missingness)`. Use the C residuals to form a smoothed empirical distribution with midrank ties. Transform the scored residual to `abs(2 * F_C(r) - 1)` and average the three rotated scores. State the exact smoothing formula in the evaluation contract. All C sources are excluded from every fit contributing to their calibration reference. The OOF errors used to fit `g` come from smaller predictors than the final R predictor; C and outer scores nevertheless use the identical R predictor and nuisance reference. This approximation, the small reference size, and the resulting discrete ranks are explicit limitations. No conformal coverage claim is made.

The fixed primary comparison is this conditional two-sided score minus the AUROC of `-E_persistence`. As a secondary control, repeat the identical R/C rotations, nuisance-reference construction, and tail transformation for `ridge_posture`, and directly compare its score with the primary posture-plus-velocity score. This matched calibration control tests whether velocity adds anomaly information beyond current posture; a static-pose distance alone cannot answer that question. Secondary scores include raw MSE, historical excess MSE, one-sided and marginal two-sided normal-reference scores, prefix motion, prefix missingness, and a normal-only static-posture distance. Keep their directions fixed. Add view or extra posture covariates only as an explicitly identified sensitivity, without changing the primary score.
