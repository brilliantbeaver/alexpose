# Independent review

Reviewer, task ID, run ID, artifact paths and identities:

State whether the reviewer authored any of these artifacts. If so, assign a different reviewer for acceptance.

For each finding, give severity, affected requirement, concrete evidence, a reproduction command or observation, and the required repair. Separate confirmed problems from unresolved questions.

Record the actual checks performed, including rendered figure inspection when relevant. Explain limitations and missing evidence.

Give the proposed disposition (`accept`, `needs_changes` or `blocked`) and what must be checked again after changes. The coordinator owns the final acceptance decision.
