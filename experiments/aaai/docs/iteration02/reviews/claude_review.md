# Independent Claude critique

This external critique is advisory, not verified evidence. It incorrectly reads a deduplicated stroke category as one source; the candidate cohort has 15 stroke sources. See the response record for accepted and rejected recommendations. Typographic dashes are normalized here; the exact model output remains in `claude_review.raw.json`.

# Review of "Instructions for the next gait research iteration" (draft02 plan)

This is an unusually disciplined protocol. The author has already internalized most of the traps I would normally flag: the estimand is a raw paired prediction-error difference rather than an AUROC; leakage controls (hidden-input noninterference, zero-gate identity, apply-restriction-before-derived-features) are explicit; an own-capacity sham control is built in; and the honesty about "28 previously-explored normal sources ≠ 28 fresh participants" is better than most published work. I will not restate those strengths. Below are the problems that remain, ranked by how badly they threaten the stated conclusions.

## Severity-ranked corrections

**1. (Fatal to the headline claim) The normal-prediction adequacy gate and the detection claim are in direct tension, and the plan does not resolve which wins.**
The core logic is: freeze `f(O)`, then add `g(O,C)` only if it improves *held-out normal* prediction. But the draft01 evidence row says full-context MSE is *worse* than own-context MSE in all four primary folds. That strongly predicts the adequacy gate will fail ; own-leg geometry nearly solves ankle completion, leaving no headroom for contralateral information to demonstrate benefit *on normals*. If the gate fails, `R=0` everywhere and `S=M/2`, so the entire relational contribution collapses to a motion-distance paper you could have written without the predictor.

Why it matters: the plan treats "improves normal prediction" as the admission ticket for `g`, but the *scientific question* is whether contralateral timing distinguishes *abnormal* gait. These are different quantities. A `g` that adds nothing on healthy regular gait could still fire on abnormal gait ; that is arguably the whole point. Conversely, a `g` admitted because it helps normal prediction may be capturing local geometry refinement, not interlimb coordination. **Correction:** separate the *estimator-validity* gate (does `g` recover the known contralateral innovation in the fixtures, with zero spurious benefit under conditional independence) from the *admission* gate. Admit `g` based on fixture recovery and non-degeneracy, not on normal-MSE improvement. Report normal-MSE headroom as a *diagnostic*, and pre-commit that a null relational result under a demonstrated ceiling is reported as "underdetermined," not "no coordination information." As written, the two-of-three-internal-folds rule will likely kill the relational arm on a technicality that is confounded with the ceiling you yourself flag.

**2. (Fatal to generalization; author half-acknowledges) n=28 previously-explored normal sources across 4 folds cannot support any population-level claim, and the reference set is dangerously thin.**
Five reference normals estimate a 2-D normal distribution (the `R` channel) with a variance floor that is itself a tuning knob. Seven test normals per fold. The plan correctly forbids 95% specificity and conformal thresholds, but *still* proposes weighted-mean-of-within-fold AUROC as the primary summary. With ~7 normals × per-fold abnormals, each fold's AUROC has enormous variance, and the four folds share fitting/reference sources (not independent). The paired source-cluster bootstrap "conditional on the fitted models" is the honest move, but readers will read AUROC=0.7X as a performance claim regardless of caveats.

Why it matters: the method's central novelty (`R`) is estimated from five recordings that were all seen in prior exploration. No amount of frozen-protocol language converts this into evidence about coordination in a population. **Correction:** demote AUROC to a secondary descriptor and make the *primary* reported quantity the paired within-source `S` vs `M` difference with its cluster-bootstrap interval, explicitly labeled exploratory-internal. Better: fold the external stroke dataset (138 controls / 50 stroke) from §13 into the *core* plan, not an optional extension ; it is the only path to a normal sample that is not pre-explored and not n≈28. See the highest-value experiment below.

**3. (Severe; semantic validity) The "timing" manipulation does not isolate timing, and the plan's own caveats admit this without resolving it.**
Shifting donor distal-leg context by ±4 frames while reattaching to the original hip "changes distal-leg timing, not the pelvis." But a ±4-frame shift of a limb trajectory *also* changes instantaneous position, velocity, and the limb's phase relationship to its own proximal joints ; it is not a pure phase/alignment perturbation. The plan requires reporting displacement/velocity changes per pair, which is good, but then names the primary effect "a measurement of whether alignment matters." A predictor sensitive to the shift could simply be sensitive to the donor now being in a kinematically implausible configuration relative to the (unchanged) target-side and shared reference.

Why it matters: this is the difference between "the predictor uses interlimb *temporal coordination*" and "the predictor notices the contralateral leg is in an unusual instantaneous pose." Only the former supports any coordination-measurement framing. **Correction:** add a *position-matched* control ; a donor substitution that changes instantaneous configuration by a comparable magnitude but preserves alignment (e.g., a within-phase donor from a different stride at the same phase), and/or report the timing effect *conditional on matched displacement/velocity change*. Without this, drop the word "coordination" entirely and call it "sensitivity to contralateral context perturbation," as the gate table already hedges.

**4. (Severe; capacity confound not fully closed) Parameter-count matching does not match effective capacity, and the plan knows this but ships it anyway.**
The own-capacity control `h(O)` vs relational `g(O,C)` is the right idea. But the plan concedes "zero-padding to match dimension does not prove equal effective capacity" and asks only to "report differences in effective basis rank." `g` sees strictly more input variables than `h`; any flexible learner can exploit them even if `C` carries no *interlimb* information, because `C` is correlated with `O` and with `Y` through whole-body dynamics and shared noise/view. The conditional-independence fixture guards the synthetic case, but on real data `C⊥̸Y | O` even for a perfectly healthy regular walker (bilateral coupling is physiological), so a benefit proves coupling exists, not that it is *diagnostic*.

Why it matters: the manuscript direction "relational prediction is informative" could be true and still clinically vacuous if the same benefit appears identically in normals and abnormals. **Correction:** the decisive quantity is not "does `g` beat `h`" but "does the `g`-minus-`h` benefit *differ between normal and abnormal sources*." Make that differential the relational estimand. The current `R` (standardized departure from a normal reference) gestures at this but is built on a 5-source reference (see #2).

**5. (Moderate; selection/population) The focal-primary endpoint was chosen after seeing all-folder results, and stroke n=1-source.**
The plan is admirably transparent that the normal-vs-four-families focal endpoint is an exploratory redesign chosen after earlier results were seen, and commits to publishing both endpoints without headline-shopping. Good. But stroke appears as a *single source* in the focal set. One source cannot support any per-condition statement, and stroke is the condition most theoretically linked to interlimb asymmetry ; i.e., the condition the mechanism most predicts should show an effect. **Correction:** state up front that stroke is anecdotal (n=1 source) in GAVD and that any stroke-specific interpretation *requires* the external dataset. This also raises #2's external-data argument to near-mandatory.

**6. (Moderate; measurement validity, correctly flagged but worth hardening) Projected 2-D angles, pose-detector-as-tracker, and no physical units.**
The plan repeatedly and correctly warns that projected trunk inclination ≠ clinical angle, pelvis-relative motion ≠ walking speed, and the extractor "returns the first detected pose in the crop" and "is not a validated temporal identity tracker." This is honest. The residual risk: `M`'s descriptors (knee-angle IQR, ankle velocity MAD) are view-dependent, and GAVD web video has heterogeneous viewpoints. A left-right asymmetry descriptor is especially view-confounded. **Correction:** the nuisance-classifier comparison (§10) must include *view* and *camera motion* explicitly, and `M`/`S` differences must survive view-stratified or view-matched analysis, not just a global nuisance-AUROC check. An asymmetry signal that is really a camera-angle signal would masquerade as pathology.

## Novelty assessment

The author's self-score of 3.5/5 novelty is roughly right, possibly generous. The components (JEPA-style masking, normal-only anomaly detection, interlimb phase/coordination indices, residual-correction framing) all exist, as the §3 table honestly catalogs. The genuine novel element is the *methodological argument*: that a two-prediction-error difference is uninterpretable without jointly controlling target-representation change, added capacity, observation-support change, and normal-prediction adequacy ; and the matched-support, frozen-answer, retained-baseline construction that makes the difference interpretable. That is a real contribution *to measurement methodology*, not to gait detection per se. It is most novel as a *negative/cautionary* result ("here is why prior context-helps claims are confounded, and here is a design that isolates the effect"). It is least novel if it becomes "another normal-only skeleton anomaly detector with an AUROC." I would push the author toward the methodological framing, which is also the one most robust to the thin-sample problem. No "first" claim is warranted and the plan correctly forbids one.

## The single highest-value experiment

**Run the frozen algorithmic contrast on the external stroke dataset (138 controls / 50 post-stroke, common-clock C3D) with participant-held-out normal fitting ; and make the primary reported quantity the *differential* relational benefit (`g`-minus-`h`) between controls and stroke participants, with real participant identities.**

This single experiment simultaneously attacks the three fatal/severe problems: it supplies a normal sample that is not n≈28 and not pre-explored (#2); it gives stroke an actual population instead of one source (#5); and because C3D marker data has true 3-D coordinates and verified per-participant identity, it removes the pose-tracker, projection, and "uploads-aren't-people" confounds in one move. Crucially, it reframes the estimand from "does context help prediction" (physiologically guaranteed, therefore weak) to "is the contralateral-information benefit *larger or structured differently* in a condition with known impaired interlimb control" ; which is the actual scientific question and the one GAVD alone cannot answer.

Caveats the plan already states and must keep: different measurement system (markers, not BlazePose ; do not relabel), bilateral timing preserved only if both limbs share one stride anchor, age/sex sensitivity retained, and this tests the *idea* not transferred video weights. Budget it generously; the plan's two-hour parsing pilot plus one working day is too tight if this becomes the load-bearing result rather than an optional extension. Reorder the schedule so the external pilot runs in the first block, because if its identities/units/missingness fail verification, you want to know before investing in the GAVD-only scoring machinery whose claims it was supposed to rescue.

One feasibility flag: you cannot BlazePose-extract a 3-D marker dataset, so the external replication can only test the *estimator logic* on marker coordinates, not the pose pipeline. State plainly that this validates the method's *claim about interlimb information*, while leaving the *video-pipeline* claim internal to GAVD and underpowered. That honest split is itself a publishable, defensible position.
