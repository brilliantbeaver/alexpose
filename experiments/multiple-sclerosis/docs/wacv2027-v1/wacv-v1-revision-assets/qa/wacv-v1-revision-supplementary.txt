 176     S8. Variation in the retained predictions
 177     We resampled source videos within each collection label
 178     10,000 times, retaining 16 Normal, 13 MS and 12 PD source
 179     draws per resample. Sampling was with replacement. Each
 180     sampled source contributed total weight one across its clips,
 181     with repeated draws counted repeatedly. All methods used
 182     the same draws. The calculation used NumPy’s PCG64
 183     generator with seed 42 and sorted source identiﬁers within
 184     each label. All 10,000 draws for Normal are generated ﬁrst,
 185     followed by all draws for MS and then PD. The 2.5th and
 186     97.5th percentiles, using linear interpolation, deﬁne the in-
 187     tervals reported here.
