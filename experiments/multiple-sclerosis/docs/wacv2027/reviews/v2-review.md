## Required changes for v3

1. **Replace the pending uncertainty sentence with completed paired analysis.** Section 5.2 currently says uncertainty “must be computed”; this is unfinished work that the saved OOF rows already permit. At the original draft's stated settings—10,000 class-stratified source resamples, seed 20261004—the notebook-anchored S-JEPA score is 0.456624 with conditional percentile interval [0.328714, 0.578793]. The paired differences are 0.004731 [−0.160496, 0.173999] versus mean pose and 0.045361 [−0.133447, 0.220114] versus historical RF. Define the resampling unit, equal total weight per sampled source occurrence, shared draws, fixed class counts, and conditioning on already fitted OOF models. These are descriptive source-resampling intervals; overlap in training sets, unknown repeat participants and unmeasured seed/selection variation prevent a confirmatory population interpretation.

2. **Quantify the corrected RF as a separately labeled verification.** Section 6 currently acknowledges that a later correction changes RF predictions but withholds the result. The corrected extraction produces macro-F1 0.325184 under source weighting and 0.320940 under clip weighting. Its source-weighted fold mean/SD is 0.305256/0.039217. Exactly 12 of 88 RF predictions change. Current feature extraction reproduces every newer RF prediction; replacing only the true left-ankle range with the right-ankle range reproduces every historical prediction. Report this as additional implementation verification, keeping it separate from the notebook-primary table. Do not suggest a new independent-seed replication: both runs use the same data, folds and seed, and S-JEPA hard predictions coincide despite numerical differences in the embeddings.

3. **Show the empirical variation that motivates the conclusion.** Add a compact fold plot or table with the notebook S-JEPA values 0.515263, 0.362559, 0.779598, 0.315654 and 0.217267, alongside mean pose. The pooled ranking reversal and four-of-five fold result are more persuasive when readers can inspect the large fold-2 advantage and the four disadvantages. A matched difference plot could communicate this more efficiently than another paragraph of qualification.

4. **Report the class-level limitation directly.** S-JEPA correctly labels 10/24 Normal, 8/29 MS and 18/35 PD clips. Source-weighted recalls are 0.395833, 0.428994 and 0.569048. The original draft's 19 PD successes and 0.611 PD recall are unsupported by either saved run. A compact confusion matrix or per-class line would connect the average score to the biomedical claim and prevent an overly favorable reading of 0.457.

5. **Name the retained evidence and distinguish reanalysis from notebook output.** The notebook-primary run is `capstone-20260921T011305448893Z` under the full-v1 registry prefix `9496e61b050f`; the corrected verification is `capstone-20261009T060955236580Z`. The latest UTC date is October 8 locally in Los Angeles. Add an artifact statement or supplementary manifest recording exact paths/hashes, relevant package versions, and the command that reproduces all manuscript numbers. State that the bootstrap is a manuscript-stage reanalysis; notebook 06 has written results and unexecuted code cells, so it has no saved bootstrap output.

6. **Tighten the contribution while preserving the limits.** “An empirical evaluation under source-separated testing” is accurate but broad. State the observed result more precisely: the learned representation's small source-weighted lead over an order-invariant control reverses under clip weighting and is concentrated in one fold. This contributes a bounded evaluation lesson. Neither a corrected RF bug nor the presence of many implementation details establishes methodological novelty. The evidence does not determine whether dynamics helped, so avoid language implying that the experiment settled temporal utility.

## What v3 should preserve

Keep the existing distinction between source-weighted clip decisions and one decision per source. Preserve collection-label terminology, the separation of checkpoint selection from outer testing, the statement that stage continuation resets optimization state, and the readout explanation that the fixed mask selects output features while the teacher sees complete inputs. The reflection limitation is appropriately described as a within-example correspondence issue; it must not be inflated into test leakage or a measured cause of the modest scores.

The ethics paragraph is candid, but a final submission still needs the authors' actual source-media and review status; prose cannot fill those missing records. No additional participant, diagnosis or permission facts should be invented in later drafts.
