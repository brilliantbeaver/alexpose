# Semantic-gauge tutorials

Tutorials in this directory must follow the decision-gate order:

1. observation and annotation audit;
2. AMASS-Gauge construction;
3. gauge posterior and transport implementation;
4. identifiability and calibration evaluation; and
5. participant-safe biomechanics validation.

Do not write a training tutorial that presupposes the method is justified before
the real-phenomenon and theory gates pass.
