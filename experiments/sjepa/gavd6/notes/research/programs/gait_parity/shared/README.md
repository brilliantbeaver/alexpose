# Shared contracts

These contracts apply to every study in the GaitParity program. They prevent a
new paper direction from quietly changing coordinate semantics, data scope, or
the unit of independent evaluation.

- [Coordinate and laterality contract](./coordinate-contracts.md)
- [Data contract](./data-contracts.md)
- [Evaluation-integrity contract](./evaluation-integrity.md)

Study-specific methods may add constraints, but may not weaken these ones.
