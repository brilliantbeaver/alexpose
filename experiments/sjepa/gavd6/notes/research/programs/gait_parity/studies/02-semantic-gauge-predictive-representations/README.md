# Study 02: semantic-gauge predictive representations

**Status:** proposed main representation-learning direction. It proceeds only
if the decision gates show a real, consequential laterality-ambiguity problem.

## Unique contribution

**Identifiability-aware semantic-gauge predictive representation learning:** a
predictive motion representation infers uncertain left/right semantic labels
over time and returns a signed biomechanical prediction only when laterality is
identified; otherwise it returns a calibrated sign orbit or uncertainty.

The claim is not that a new reflection-equivariant architecture exists. The
claim is that predictive representations must distinguish sensor-coordinate
changes from anatomical-side semantics, infer a latent semantic gauge, and
represent the irreducible ambiguity of parity-sensitive targets.
