# Decision gates

## Gate 0: fixed-reflection baseline validity

Implement branch-specific orbit-closed masks and pass copyability,
validity-aware attention, and commutation checks. This creates a valid baseline;
it does not validate Study 02.

## Gate 1: real phenomenon

Before expensive model development, measure whether GAVD pose observations show
laterality ambiguity or extractor disagreement at a non-negligible rate and
whether it affects parity-sensitive features. If not, state that the study is a
controlled robustness benchmark or stop it as a main-paper direction.

## Gate 2: theory distinction

Write the observational model, impossibility result, and anchored recovery
result. Check explicitly that they do more than restate probabilistic symmetry
breaking or generic synchronization.

## Gate 3: controlled causal test

On AMASS-Gauge, show that fixed equivariance, temporal correction, and ordinary
synchronization each fail in a predictable regime that the full method handles.
Report calibration and set coverage, not only mean error.

## Gate 4: external usefulness

Show participant-safe value for an anchored odd mechanics target and an even
stability/balance outcome. A result only under injected corruption does not
support a broad real-world claim.
