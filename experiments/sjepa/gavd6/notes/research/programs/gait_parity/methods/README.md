# Legacy method entry points

This directory preserves runnable methods for the fixed-reflection studies.
Canonical study scope and cross-study constraints live in [Studies](../studies/)
and [Shared contracts](../shared/).

- [GAVD fixed-reflection protocol](./METHODS_GAVD_ICLR.md) is Study 01.
- [Fixed-reflection signed-force protocol](./METHODS_FORCE_FUTURE.md) is Study 03.

Study 02's theory, method, and decision gates are kept together in its
[semantic-gauge study directory](../studies/02-semantic-gauge-predictive-representations/),
so a baseline implementation cannot be mistaken for the new method.
