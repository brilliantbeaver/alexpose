# Historical prompt transcripts

These files preserve requests that led to earlier notebooks, analyses, and
research-planning material. They are not current execution instructions.
Several reproduce paths from retired workspaces or from earlier repository
layouts; those paths are intentionally retained as part of the historical
record and must not be followed.

For current work, start with the [study index](../../docs/studies/) and the
[research-notes index](../README.md). Historical reports and proposal material
are under [notes/archive/](../archive/).
