# URTC 2026 GAVD package — historical record

This is the self-contained paper, tutorial, result ledger, figure set, and
generation code for the augmented-normal five-stage GAVD experiment documented
through 2026-08-25. It is retained without rewriting its claims or numbers.

It is **not current documentation**: later Core11 probe workflows, the
orbit-closed-mask repair, and the Latent Laterality research program changed the
active evidence and execution path. The generators also expect the original
`cache/artifacts/real` artifact contract, which is not present in this checkout.

Use this package for provenance or to reproduce the historical environment, not
to select a current checkpoint, report a current result, or plan a new run.

- `staged_sjepa_gait.{md,tex,pdf}`: historical manuscript
- `staged_details.{md,pdf}` and `staged_evolution.md`: historical tutorials
- `progressive_training.md`: historical training contract
- `result_history.csv` and `figures/`: preserved historical result materials
