# Paired synthetic 2D pose restoration

This additive study asks whether paired synthetic supervision improves pose restoration while preserving motion, and whether latent JEPA adds value beyond matched coordinate learning. The implemented milestone is **software- and fixture-tested**. No HAIC model run, real development reference study or protected confirmation was completed.

Start with the [short illustrated proposal](proposal/README.md) ([HTML version](proposal/proposal.html)). Read the [notebook guide](../../../notebooks/synthetic_training_v2/README.md), [delivery report](report.md), [protocol](protocol.md), [artifact audit](artifact-audit.md), [literature ledger](literature.md), [review dispositions](review-dispositions.md), and [HAIC runbook](../../../slurm/synthetic-training-v2/README.md).
