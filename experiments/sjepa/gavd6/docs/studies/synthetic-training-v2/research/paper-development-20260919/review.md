# Independent review of the paper-development plan

19 September 2026. Three independent agents researched dataset/reference quality, statistical design, and contribution/method validity in parallel. Each then adversarially reviewed the integrated [plan](README.md), and all three checked the resulting revisions. The root author reconciled the recommendations and retains responsibility for the plan. This review assesses a proposed research program; it is not peer review, an acceptance forecast or validation of experiments that have not run.

The supporting memos are [dataset-audit.md](dataset-audit.md), [stats-audit.md](stats-audit.md), and [novelty-audit.md](novelty-audit.md). The statistics work independently reconstructed 60 retained person-level contrasts and generated conditional sample-size sensitivity calculations. The dataset and novelty work relied on the primary sources linked in their memos. No new scientific training, external submission, dataset download or access application was performed.

| Challenge | Revision and disposition |
| --- | --- |
| Position accuracy versus smoothness already has substantial prior art. | The plan now requires a useful new explanation or boundary on paired feature prediction, with independent data and credible alternative recipes. A replicated null for the local model and corrections to its evaluation protocol are explicitly insufficient by themselves. |
| A motion-target JEPA could win only because it receives more supervision or capacity. | The direct comparator must receive the same coordinate and motion targets, with matched tuning allowance and explicit capacity/compute reporting. A shuffled-motion-target control remains mandatory for attribution. |
| The candidate was too underspecified for a next-day freeze. | The plan identifies unfinished teacher-update, frame/token alignment, support, capacity and compute decisions. Five-frame displacement at 25 Hz cannot silently become a four-frame token difference. The Day-2 schedule is conditional on data and implementation checks. |
| The online encoder differs from the downstream encoder used in published S-JEPA. | Online-versus-momentum-teacher probing is a recipe diagnostic before architectural expansion. The local restoration result is not presented as a failed reproduction of action-recognition S-JEPA. |
| A successful probe does not prove why the restoration head failed. | Probe access, aggregation and coordinate-training budget must be matched. Probe success identifies accessible information; causal attribution requires a controlled output-stage intervention. |
| ViTPose has already influenced development decisions. | Its role is described as excluded from restoration fitting, not unexamined during method selection. Fresh-person testing remains possible; genuinely new-family claims require a previously reserved family. |
| Excluding AMASS BMLmovi does not establish that other BioMotionLab people never recur in MoVi. | The conservative design excludes all potentially overlapping BioMotionLab sources pending a reliable crosswalk. Unknown identities remain unknown; a corpus name alone is not proof of independence. |
| Only refitting the candidate would leave old controls exposed to a different training population. | Every learned restorer and fitted calibration control must use the same fresh roster. Existing BML-trained models remain development diagnostics unless overlap is resolved. New roster preparation/rendering/extraction is identified as a critical dependency. |
| MoVi's advertised population and real-video status could be overinterpreted. | Access and actual usable counts remain unverified. F/PG video is proposed with its marker/minimal-clothing limitation; natural-clothing ankle evaluation is a separate S1/S2 extension. |
| Reference conventions and the primary population were still selectable. | The plan proposes F-round walking, PG2, natural video, projected Visual3D shared joints, fixed window scale and person-balanced averaging, subject to an initial import check. Mapping, rate, eligibility and weights must be frozen before test predictions. MoSh++ is a separately named reference sensitivity analysis. |
| Power against zero could be confused with proving a useful minimum improvement. | The 61-person example is a hypothetical 5% true effect against zero, conditional on fixed models. The plan separately defines a lower-bound requirement for demonstrating a minimum benefit and an upper-bound requirement for position noninferiority. Unknown seed and transfer variance remain explicit. |
| A fallback story could be chosen after observing confirmation outcomes. | Intended empirical contrasts and their multiplicity plan must be declared before test results. New explanations selected afterward stay exploratory. |
| A long baseline list could create a rushed, unfair comparison. | The core representation controls take priority, followed by a verified refiner. A new-method performance claim requires a credible recent competitor; an unreliable port cannot stand in for it. |
| Diagnostic line plots cannot certify input/reference quality. | The gallery's four-person/four-window scope is explicit. Full synchronized RGB/crop/reference playback is still required for data acceptance. The existing producer saves only a few three-frame overlays. |
| Two summary images were missing from the gallery hash manifest. | The builder and manifest now cover all 58 images. The dataset reviewer independently verified every path and hash. |

All three final reviewers reported that their critical documentation concerns were resolved. They retained substantive evidence conditions: access and eligible counts, identity separation, annotation compatibility, a verified reference adapter, training roster replacement, candidate and baseline implementations, seed variability, practical margins and measured throughput. No amount of prose review removes those requirements.

**Artifact checks**

The data-review page contains 48 trajectory figures, eight training histories and two population-level figures. JavaScript syntax was checked; all 48 person/estimator/condition combinations, eight training choices, three view switches, required note fields and CSV-note export passed an isolated DOM behavior check. The initial local page load and its labels were observed in native Chrome. Subsequent control behavior was tested in isolation rather than claiming a completed interactive browser walkthrough. Test notes existed only in the isolated runtime and were not written into the scientific data.

The [gallery manifest](data-review-manifest.json) hashes its generated page, generator, metadata selection and every image. The [statistical verification](stats-verification.json) records source hashes, recomputed contrasts, formulas and numerical sensitivity checks. The final [delivery validation](validation.json) records local links, image hashes and source preservation. Scientific source files, existing abstracts and original experiment outputs remain unchanged by this task.
