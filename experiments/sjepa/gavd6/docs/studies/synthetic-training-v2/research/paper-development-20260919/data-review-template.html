How to read these plots
  • Each row shows one ankle coordinate in image pixels over physical seconds. Image y increases downward.
  • The left column compares spatial corrections. The right compares learned restoration. The black line is the valid synthetic reference, including joints hidden from view.
  • Follow the plotted legends: colors are reused between columns. Gaps preserve missing input observations. No temporal interpolation was added to these input curves.
  • Look for position offsets, changes in movement size, delays, extra oscillations and severe excursions. A closer average position can coexist with altered movement.
  • Coordinate scales match the two columns within each row, but can differ between separate figures. Open an image for full resolution. Individual examples do not estimate population reliability.
