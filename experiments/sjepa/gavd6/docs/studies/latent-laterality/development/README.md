# Latent Laterality (Study 02)

**Predictive motion representations under unknown left/right correspondence.**

**Status:** seed-7 validation complete; confirmation stopped.

This study asks whether a representation can infer and retain uncertainty over
time-local bilateral token-correspondence errors, rather than applying a
post-hoc correction. The uniform-uncertainty control reproduced SG-JEPA's
validation gain. Read the [completed findings](../results/validation.md)
before further work. Do not run confirmation seeds 19/31 or open the test split
under the current plan. A continuation needs a new exploratory question.
