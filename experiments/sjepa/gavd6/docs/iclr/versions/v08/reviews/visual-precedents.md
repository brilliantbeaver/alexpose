## Paper-specific visual specification

The following is a design recommendation for this manuscript, not an ICLR font-size rule. Compose at the final 5.5-inch text width, typically 2.4–3.2 inches tall. Use 8–9 pt axis/annotation text, 9–10 pt panel headings, dark neutral text on white, light horizontal guides only when they aid comparison, 0.6–0.8 pt axes, approximately 1 pt intervals, and readable markers. Embed fonts in PDF and retain vector text/line art. No rounded cards, shadows, decorative icons, or quantitative-looking color gradients without a quantity.

Reserve semantic encodings across figures: method identity uses a small accessible palette; readout objective uses redundant marker shape; adaptation regime uses group headings/spacing. Anatomical L/R must use explicit letters or distinct anatomical marks rather than reusing method colors. A black dashed reference can denote zero prediction on the response axis only. Use a neutral direct-training reference where it is a practical benchmark rather than a matched frozen-encoder control. Confirm every meaning in grayscale.

| Figure question | Composition | Guardrail |
|---|---|---|
| What is paired, supervised, and deployed? | Two state columns with observed and projected-reference rows; concise mathematical feature comparison; a separated one-state inference strip. Use only essential arrows. A small note distinguishes algebraic excursion exchange from physical reprojection. | No apparent equivariance guarantee; no invented motion reconstruction. Training-only reference privilege and frozen deployment path must be visible. |
| Does restoration improve movement fidelity? | Aligned response/waveform axes with the same method order; separate joint-training and frozen-readout groups; objective markers; zero response only on response. Add paired effect intervals where recoverable. | A shared degree unit does not imply equal outcomes. Show all selected families or point to a complete appendix. |
| What drives the apparent gain? | Coordinated panels for rates, unconditional score contributions, and paired response effects. Distinguish response and waveform effects spatially when interval procedures differ. | Rates are percentages; contributions are degrees; successful-only error uses a different denominator. Never stack a rate with an error. |
| How does supervision repair change waveforms? | Original/low-scalar/dense absolute means and corresponding paired effects in adjacent panels; clearly identified direct-training reference. | The 93% ratio is subordinate. Do not infer intervals for differences from marginal bars. |
| Which naming conditions fail? | Three aligned naming-condition panels or grouped points with the same 0–100% axis and method symbols. | No lines implying continuous category transitions or 50% chance baseline. Decompose wrong/ambiguous/missing only from verified exports. |

Before accepting the visual system, inspect the main empirical prototype and method prototype inside the manuscript at normal reading size. Then inspect every final PDF page and grayscale render for hierarchy, collisions, small labels, full interval extent, and denominator/estimand clarity. The full figure set should look designed around these comparisons, rather than like the previous diagrams with smaller fonts.
