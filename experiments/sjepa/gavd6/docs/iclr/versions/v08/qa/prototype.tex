\begin{abstract}
We examine whether predicting reference features improves the restoration of side-sensitive movement changes from noisy pose observations. This figure prototype checks scientific relationships and actual reading size in the official manuscript template.
\end{abstract}
\section{Controlled restoration}
States $a$ and $b$ share a source movement window. Physical mirroring changes both reference and rendered observation; naming corruption changes the observation alone. The model processes one state at inference. The mathematical schematic represents executed relationships and contains no synthetic example presented as a model result.

\section{Does restoration recover movement change?}
Lower response error relative to observed coordinates does not establish useful change recovery. The zero-response benchmark is lower than every neural method in the pooled export. The next figure distinguishes jointly trained direct fitting from frozen-encoder readouts, and separates absolute scores from the paired effect of supervision.
