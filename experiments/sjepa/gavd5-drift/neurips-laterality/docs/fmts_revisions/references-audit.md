The existing `assets/v9/` directory, TeX, PDF, manifests and submission ZIPs are frozen snapshots under the [revision policy](README.md#reproduce-a-manuscript). This standalone correction does not change those snapshots or the bibliography path in `paper_v9.tex`. To use it in an extracted v9 source package, replace that package's `assets/references.bib` and recompile.
