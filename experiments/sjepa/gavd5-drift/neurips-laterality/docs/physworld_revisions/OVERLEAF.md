# LaTeX, PDF, and Overleaf versions

Each retained `paper_vN.md` has a matching `paper_vN.tex`, compiled `paper_vN.pdf`, and self-contained `paper_vN_overleaf.zip`. The conversion leaves its Markdown source unchanged. Use **revision 8** as the current manuscript. It keeps v7's evidence, citation, and precision corrections while rewriting the paper in direct language. Earlier manuscripts preserve the previous stages of revision.

The [workshop CFP](https://physworld-org.github.io/physworld.github.io/cfp/) requires NeurIPS 2026 style and double-blind review. Long papers may have at most **eight main-text pages**, excluding references and appendices; the extended-abstract limit is four. These projects use the long-paper format. Formatting is not authorization to submit: the manuscripts still describe unresolved institutional ethics, data-use, and release reviews. Nothing has been uploaded or submitted.

## Upload and compile

1. In Overleaf, choose **New Project → Upload Project**, then upload the ZIP for your chosen revision. You do not need to upload the repository or the other projects. See [Overleaf's project-upload instructions](https://www.overleaf.com/learn/latex/Kb/Uploading_a_project).
2. Set the matching `paper_vN.tex` as the main document. Its file menu has **Set as main document**; the main document can also be selected in the compiler settings. See [Overleaf's main-document guide](https://docs.overleaf.com/getting-started/recompiling-your-project/the-main-document).
3. Select **XeLaTeX** as the compiler and recompile. The local PDFs were generated by Tectonic 0.17.0, which uses XeTeX. There is no BibTeX step: each `.tex` contains its bibliography and citation keys.
4. Check the resulting PDF, including figure labels, references, and the page on which References begins. Overleaf's TeX Live version may differ from the local compiler's bundle, so recheck pagination after editing or changing the compiler.
5. Download the compiled PDF. Uploading a project to Overleaf does not submit it to the workshop.

Keep these settings for double-blind review:

```tex
\usepackage[dblblindworkshop]{neurips_2026}
\workshoptitle{Physical World AI: Geometry, Characteristics, and Multimodal Sensing}
\author{Anonymous Author(s)}
```

Do not add `final`, `preprint`, `nonanonymous`, or `sglblindworkshop` for anonymous review. The official style supplies the generic anonymous affiliation/address/email block, review line numbers, and “Submitted … Do not distribute” footer. Those are expected in review mode. Do not edit the style merely to replace that footer with a workshop-specific one. The local style was checked against the [official NeurIPS 2026 author kit](https://media.neurips.cc/Conferences/NeurIPS2026/Formatting_Instructions_For_NeurIPS_2026.zip).

## What changed during typesetting

The conversion extracts the title and abstract, removes the dated working-copy badge, and uses consistent automatic section numbering. It repairs malformed math delimiters where needed while preserving the mathematical expressions. Short tables are kept together. The body font, margins, and page geometry remain those supplied by the official style.

Source links become numbered references in first-citation order. V7 and V8 each validate their 16 citations against their own Markdown bibliography; V8 no longer inherits V7's reference text. V8 corrects the GAVD author's surname to Ali Armin and the punctuation in the GaitJEPA entry. Separate records remain for sources used only by V1-V6. References use the normal heading size and permitted 9-point entries. The official author kit accepts numerical or author-year citations and does not require a separate BibTeX file. See the [V8 claim review](../README.md#v8-adversarial-claim-review) and [citation review](../README.md#citation-and-reference-review--10-september-2026).

Repository-local audit links retain their descriptive text without broken file actions in the PDF; the actual audit documents remain available through the parent [review README](../README.md).

V5-V8 use print-sized vector figures with readable labels. V5 and V6 also include the expanded pipeline and a landmark-selection schematic. V7 and V8 include two main figures and one supplementary reflection schematic. The V8 review corrected the shared compact pipeline: complete poses feed the teacher's own embedding, and the student masks projected tokens. Notebook identifiers were removed from its labels. Plotted results are unchanged. V8's working-copy date and revision badge have been removed from Markdown; the PDF retains the official anonymous author metadata.

## Rebuild locally

To compile an existing `.tex`, run XeLaTeX twice from this directory, for example:

```sh
xelatex paper_v8.tex
xelatex paper_v8.tex
```

Alternatively, Tectonic resolves the necessary reruns automatically:

```sh
tectonic paper_v8.tex
```

To regenerate all TeX sources from the retained Markdown and rebuild the project ZIPs, use Python with `pypdf`, Pandoc, and Tectonic:

```sh
python build_submission_versions.py --pandoc pandoc --tectonic tectonic
python package_overleaf_versions.py --tectonic tectonic
```

The first command overwrites only the generated `.tex` and `.pdf` versions, never the Markdown originals. The second refreshes the ZIPs and build manifest, then tests each extracted ZIP as an isolated project. Make lasting edits in Markdown or in the conversion script; hand edits to generated TeX will be replaced by the next source rebuild. To maintain TeX directly, keep an independent copy of its Overleaf project.
