# Figure status

## Current v2.1 figures

The manuscripts use three figures, all generated by `make_v21_figures.py` directly from the completed held-out report so they cannot drift from the verified numbers:

- `v21_group_action` — bilateral reflection as a group action on a real GAVD-derived pose (sequence 327). Flipping the horizontal axis and swapping anatomical left/right landmarks produces a valid pose representation and reverses the coordinate-derived target `y`. This is the paper's Figure 1.
- `v21_learning_effect` — what self-supervised training changed, as learned-minus-untrained differences with 95% source-cluster bootstrap intervals. Panel (a) is predictive utility across the free and constructed read-outs; panel (b) is the strict token equivariance error for both variants. This is the paper's Figure 2 and the extended abstract's Figure 1.
- `v21_absolute_levels` — absolute levels against the frozen thresholds. Panel (a) is the source-balanced $R^2$ ladder (oracle, learned free, constructed odd, nuisances); panel (b) is geometric fidelity (learned and untrained token error, native output error, constructed output) against the 0.10 margin. This is the paper's Figure 3.

Each figure is written as both PDF (for the LaTeX build) and SVG. The script also dumps `v21_figure_numbers.json`, the exact estimates and intervals it read from the report, so the figures and the manuscript prose can be cross-checked.

### Regenerating

The script reads from `artifacts/paper/protocol_<digest>/report/` (checkpoint, equivariance, and native-symmetry bootstrap CSVs, plus `metrics.csv`) and from the cohort archive. Run it with the project environment:

```
../../../.venv/bin/python make_v21_figures.py
```

New figures should be generated only from complete v2.1 held-out evaluation artifacts carrying the matching protocol, cohort, split, checkpoint, and implementation digests.

## Superseded assets

Any older `fig1`–`fig6` PDF/SVG files in this directory belong to the superseded exploratory, transductive analysis and are retained only as historical working assets. They describe a six-pair temporal-variation target rather than the registered five-pair paired-valid velocity target, one encoder that had seen the evaluated sequences, repeated reshuffled cross-validation, and legacy cohort counts and estimates. They must not be included in a v2.1 manuscript, presentation, or result summary.
