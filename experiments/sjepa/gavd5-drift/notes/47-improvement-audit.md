# Implementation and evidence audit for the S-JEPA improvement plan

Audit date: 2026-09-15. Companion to [47-improvement-plan.md](47-improvement-plan.md). This audit inspected the local `neurips-laterality` notebooks, their authoring sources and implementation, retained numerical evidence, and the latest [FMTS paper v9](../neurips-laterality/docs/fmts_revisions/paper_v9.md). It did not run new training, locate full-video data, connect to HAIC, or inspect any HAIC video directory. New experiments must receive the user's full-video and walking-sequence locations explicitly.

The strongest retained result is a **within-cohort evaluation failure whose aggregate arithmetic can be reproduced**: the tested pretraining recipes improve a same-clip feature-matching diagnostic while reducing the accuracy of the selected movement readout. Raw inference and bootstrap replay remain unavailable locally. The evidence does not identify the cause, establish clinical meaning, demonstrate general information destruction, or evaluate real-gait forecasting. The next experiment should distinguish measurement loss, readout limitations, objective mismatch and observation shortcuts before expanding mask searches.

## 2. What the retained numbers support

The latest comparison uses 625 accepted clips from 93 sources, originating from 666 selected annotations and 642 pose archives. Accepted annotation counts are normal 270 clips/29 sources, myopathic 183/28, stroke 75/18, cerebral palsy 58/9, and Parkinson's 39/9. These are dataset annotations, not independently verified clinical diagnoses. Five test folds contain 189, 182, 72, 77 and 105 clips, with 19, 19, 19, 18 and 18 sources. All windows or derivatives from a source must stay in its partition.

Five conditions × five outer folds × five seeds produce 125 trained encoders. Each receives 1,200 updates at batch size 20: 150,000 arm-updates and 3,000,000 clip presentations across the grid. The same clips and sources recur; those presentations are not independent observations. For each seed the implementation pools predictions across the five outer folds, calculates source-balanced R², then averages seed scores.

## 3. Prioritized findings and falsifiable repairs

### P0. Preserve time and observation support before changing the model

**Evidence.** [geometry.py](../neurips-laterality/laterality/geometry.py), lines 83–107, fills gaps by sample index and declares filled observations valid. Lines 153–168 resize using `linspace(0,1,len(values))`, and lines 196–205 resize normalized input to 64 positions. Actual frame numbers only become times for the separate target path at line 211. The target divides displacements by each original positive time interval at lines 238–264. Target and input normalization also use different pelvis-fallback and validity rules. The retained agreement check on 623 clips/92 sources gives R² ≈0.218, correlation ≈0.652, MAE ≈0.041 and sign agreement ≈70.4%.

**Important correction.** Missing *absolute duration alone* does not explain this signed normalized-speed target. If every interval is uniformly multiplied by `c`, both median speeds are divided by `c`, and their ratio is unchanged apart from the tiny fixed epsilon. The substantive threats are irregular frame gaps treated as equally spaced samples, smoothing/aliasing from resizing, changed common support, and normalization differences. Duration and timestamps are essential for future physical-time targets and cadence, but appending one duration scalar is not a demonstrated fix for the historical ratio. The input/target agreement is neither an information-theoretic ceiling nor proof of irreversible information loss.

**Repair.** Build fixed-duration windows from the full available walking sequences with original timestamps, track IDs, frame numbers, frame dimensions, observed/interpolated status and confidence. For each window retain a raw measurement path and explicitly specified encoder path. Use interpolation limits in seconds and never bridge a tracking break or turn boundary unintentionally. Apply appropriate anti-aliasing before downsampling. Preserve a real-time clock and validity rather than stretching every full video to 64 indices. For a prospective forecast, estimate every normalization quantity from its available prefix only and freeze that coordinate frame for target scoring.

**Falsifier.** On training sources, compare one factor at a time: sample-index versus timestamp sampling; interpolation off/on; matched versus historical common support; target pelvis rule versus encoder fallback; native-rate versus anti-aliased downsampled input. If agreement and matched-initial accessibility do not improve, preprocessing is not sufficient to explain the deficit. Unit tests must preserve the ratio under uniform time dilation and show sensitivity to deliberately nonuniform timing when expected.

### P0. Separate self-supervised data eligibility from this one readout target

**Evidence.** [data.py](../neurips-laterality/laterality/data.py), lines 475–483 and 527–538, computes the target during cohort creation and excludes `target_not_computable` before accepting encoder inputs. [config/protocol.json](../neurips-laterality/config/protocol.json) limits the current inventory to five conditions and 642 archives. This is a legitimate locked historical cohort, but using it as the only SSL training universe discards unlabeled sequence material precisely when the intended advantage is self-supervision.

**Repair.** Create independent manifest flags for `ssl_eligible`, `forecast_eligible`, `laterality_eligible` and each independent downstream endpoint. SSL eligibility should use prespecified observation/track QC without requiring a complete five-pair target or disease annotation. Preserve source partitions before creating windows: full-video SSL must not include unannotated frames from a held-out source. The full-video availability is supplied by the user; do not discover it by filesystem or HAIC searches.

**Falsifier.** Compare the expanded training-only SSL corpus with the locked historical corpus at matched source and compute budgets. Record unique sources, walking seconds, sampled windows, and effective source exposures separately. Improvement due only to more windows of the same 93 sources is not evidence of population-scale generalization.

### P0. Change the primary scientific endpoint from re-estimating the same pose formula to future observables

**Evidence.** [geometry.py](../neurips-laterality/laterality/geometry.py), lines 217–269, calculates a deterministic pose-derived speed contrast. It averages five bilateral contrasts equally; ankle, heel and toe measurements provide strongly related lower-limb views, and opposite pair signs can cancel. The score uses speed magnitudes and is invariant to reversal of a sampled trajectory with corresponding time intervals. It does not measure temporal direction, phase, stride timing, foot loading or clinical impairment. Using a formula based on the same observed pose as the label tests accessibility of that statistic, not independent clinical validity.

**Repair.** Retain the historical contrast as a secondary diagnostic and implementation oracle. Add prefix-to-future endpoint/displacement prediction at prespecified physical-time horizons as the primary near-term outcome. Retain last-position, constant-velocity, source-trained direct-pose regression, a matched-initial encoder, supervised-from-scratch capacity control, and shuffled-future training controls. Where independent ratings or measured gait events actually exist, specify a separate outcome and assess its reliability; do not promote condition-folder names into diagnoses. Report bilateral pair-wise vectors and unsigned magnitude as secondary measurements so cancellation is visible.

**Falsifier.** Require the proposed representation to outperform strong temporal and matched-initial controls on the same endpoint support. A method that only improves recovery of the historical ratio or its own latent target has not established useful future dynamics. A raw-pose calculation that reproduces its own target exactly is a pipeline oracle, not a learned clinical benchmark.

### P0. Retain source separation, but strengthen the future split and development contract

**Evidence.** [splitting.py](../neurips-laterality/laterality/splitting.py), lines 48–143, creates source-level folds and checks source coverage and non-overlap. [motion_structured_training.py](../neurips-laterality/laterality_extensions/motion_structured_training.py), lines 86–152, keeps only outer-training tensors in the resident bank and rejects test-source schedule entries. This is a strength; the reviewed paths do not show ordinary clip-level train/test leakage. Source identity is not participant identity, however, and the target and readout were developed using this cohort.

**Repair.** Group all derivatives, overlapping windows, reuploads and known same-person recordings at the strongest verified grouping level. Keep unknown person IDs unknown. Publish the group hierarchy and exactly which generalization is tested. Use a new prospective holdout when available; otherwise label further comparisons exploratory. Model recipes, mask choices, training budgets and stopping rules must be selected on validation sources excluded from that candidate's SSL training. Current inner readout CV may see encoder-pretrained unlabeled examples; that is stated and acceptable for ridge selection conditional on that encoder, but it is not strict nested selection of the whole SSL recipe.

**Falsifier.** Recompute group-overlap tables and nearest-duplicate audits before training. Any train/test shared acquisition group invalidates that split. Any experiment whose eligibility or hyperparameters were chosen from outer-test outcomes remains development evidence even if every file hash passes.

### P1. Diagnose the readout bottleneck with controlled summaries and stronger direct-pose baselines

**Evidence.** [motion_readout.py](../neurips-laterality/laterality_extensions/motion_readout.py), lines 90–158, adds mean, standard deviation, absolute differences, and support fractions together. At width 96 this expands 960 mean features to 2,890 inputs, fitted from 74–75 training sources. SD is order invariant; absolute increments discard direction; support fractions can encode missingness. [masked_learning.py](../neurips-laterality/laterality_extensions/masked_learning.py), lines 421–440, uses only 264 mean/SD/mean-displacement/validity features for the “direct pose” baseline. It does not include median bilateral normalized speeds, spectral/cycle summaries, or a learned temporal decoder.

**Repair.** On fixed encoders, compare means; means+SD; means+absolute increments; means+support; motion components without support; support-only; and full summaries. Use a matched-dimension control and training-only PCA or a compact temporal decoder to distinguish representation content from feature-count effects. Include stronger timestamp-aware raw-coordinate, bone-vector, joint-angle and velocity baselines. Fit dimensionality reduction, normalization, hyperparameters and any temporal pooling only on training partitions. Report block-change units honestly as feature change per prepared block unless real timestamps are used.

**Falsifier.** If support-only or static summaries explain the gain, do not call it learned ordered dynamics. If a compact nonlinear or temporal readout restores a trained-over-initial benefit, the original failure was partly a readout-accessibility result, not proof that training erased the information. If strong direct-pose methods match the new representation, justify the representation with transfer or label efficiency rather than raw R² alone.

### P1. Resolve ridge-range and parameterization issues before interpreting encoder inferiority mechanistically

**Evidence.** The latest grid is `(0.01, 0.1, 1, 10, 100, 1000, 10000)` in [motion_readout.py](../neurips-laterality/laterality_extensions/motion_readout.py), line 23. The retained paper reports the maximum alpha selected in 49/125 trained-teacher and 96/125 trained-online expanded-readout fits. [comparative_evaluation.py](../neurips-laterality/laterality_extensions/comparative_evaluation.py), lines 89–162, correctly fits imputation/scaling inside source-separated inner folds. Its inner partitions are sorted-source chunks, rather than the registered annotation-stratified inner folds from 00–06. `source_weights` sums to the number of sources, so an unnormalized sklearn Ridge alpha does not have an invariant effective scale when the number of sources changes.

**Repair.** Predeclare a wider log grid and report inner validation curves, boundary optima, feature variance and effective degrees of freedom. Prefer an explicitly normalized ridge objective, or record how sklearn alpha scales with total sample weight. Reuse one declared source-partition definition consistently across compared probes. If recipe selection is added, reserve an encoder-excluded validation set. Do not assume that increasing alpha will improve outer-test R².

**Falsifier.** If the optimum lies well inside a widened grid and a trained deficit remains across matched-dimensional/temporal readouts, insufficient ridge range becomes a weaker explanation. A newly improved test score after repeated outer-test inspection is exploratory, not retrospective validation of the old interval.

### P1. Increase the scientific difficulty of masks deliberately; do not confuse the configured fraction with all-token coverage

**Evidence.** [motion_structured_masks.py](../neurips-laterality/laterality_extensions/motion_structured_masks.py), lines 194–205, sets a shared hidden count from **the batch minimum valid count among 12 gait joints**, then samples motion/uniform targets across 33 joints. The real audit averages 80.771 targets and approximately 17.0% of valid all-joint tokens hidden despite `mask_fraction=0.5`. Regions hide approximately 9.9%; the matched random control leaves immediate temporal brackets at 69.9% of targets, while connected regions remove them. Connected regions still leave a visible anatomical neighbor for about 51.2% of targets. Whole trajectories and interior gaps have different budgets and were audited but not trained in the final grid.

**Repair.** Express the mask policy in measured all-valid-token, joint-group and temporal-duration units. Compare one or two prespecified harder geometries against their own count-matched random controls, using per-clip ragged masks with explicit weights. Evaluate contiguous temporal gaps, bilateral correlated masks and forecast suffixes as different tasks. A forecast mask and its query schedule must depend only on allowed prefix information. Motion weights should account for observation confidence, tracking jumps and camera/root movement, not reward raw displacement unconditionally.

**Falsifier.** Verify count matching, intervention strength and remaining cues before training. If a harder mask merely degrades endpoint utility or removes asymmetry-specific evidence, reject it despite lower local-cue counts. Large “motion enrichment” under the same score that selected the mask is intervention verification, not an independent quality metric.

### P1. Inspect the learning objective, teacher lag and partial temporal collapse jointly

**Evidence.** The implemented objective uses centered, sharpened softmax cross-entropy across teacher feature channels with temperatures 0.06/0.10, plus a pooled VICReg term. See [motion_runtime.py](../neurips-laterality/laterality_extensions/motion_runtime.py), lines 41–71; [model.py](../neurips-laterality/laterality/model.py), lines 291–316; and [motion_structured_training.py](../neurips-laterality/laterality_extensions/motion_structured_training.py), lines 343–381. VICReg is applied after pooling the 12 gait joints over the complete clip, so it does not directly require useful within-clip temporal variation. No reflection loss is used in the 125-encoder grid.

The runner uses constant LR 0.001 and EMA momentum 0.999 for 1,200 updates. The initial EMA coefficient after that budget is `0.999^1200 ≈ 0.301`; its update half-life is about 693 steps. This makes lag a testable budget-relative factor, but online encoders also underperform, so lag alone is already insufficient. A 1,200-update run presents 24,000 clips, not 300 complete passes through all 436–553 training clips. “300 epochs” historically meant source sampling, with approximately four updates per source pass.

The historical audit records first/final predictive loss ≈15.08→0.849 for motion-uniform, 15.04→0.835 for MAMP and 15.13→0.948 for connected regions. Lower loss against a moving teacher is not a convergence or utility criterion. Retained standardized-summary effective ranks are ≈32.2 initial, 34.0 teacher and 39.2 online for mean-motion, and all 875 standardized feature rows have `near_constant=False`. This argues against complete constant collapse; it cannot rule out loss of useful low-variance motion directions or a representation dominated by static variation.

**Repair.** Preserve the present objective as an exact legacy arm. Compare a normalized latent-regression JEPA arm against it using the same source draws, windows, encoder and predictor, with a documented literature-faithful objective. Add explicit within-sequence dynamics diagnostics and, if justified, a separate velocity/displacement preservation loss. Distinguish self-supervised coordinate supervision from any clinical-label supervision. Test pooled-only versus temporal/token-level variance constraints, and measure each loss component and gradient contribution. Use a short training-only budget study with initial and intermediate checkpoints before choosing a longer production schedule. Document EMA half-life, warmup, LR decay, batch size, token exposure and compute.

**Falsifier.** A change is useful only if it improves a common observable downstream endpoint, not just its own teacher error, feature rank or reflection residual. If more training further reduces readout quality, reject a simple undertraining explanation. If regression and cross-entropy behave the same after input/readout fixes, the loss family is not the identified cause.

### P1. Make the positive predictor diagnostic sensitive to motion rather than merely clip identity

**Evidence.** [comparative_evaluation.py](../neurips-laterality/laterality_extensions/comparative_evaluation.py), lines 604–615, chooses a different source with valid teacher measurements at the same hidden positions. This correctly controls joint/time query identity and unavailable targets. It does not match viewpoint, static posture, extraction quality or motion statistics, and each arm has its own learned teacher space. A model can pass using static geometry or observation structure. Current energy normalization does not put different teacher representations into a common semantic metric.

**Repair.** Add training-prespecified controls: wrong temporal segment from the same walking track; phase-shifted sequence; static-pose sequence preserving a chosen pose distribution; temporally shuffled or block-permuted context; and matched-view/quality other-source negatives where metadata is available. Report the raw coordinate/observable metric alongside latent diagnostic scores. Use multiple negatives and source-balanced clip-level effects; keep all transformations at the proper information boundary.

**Falsifier.** If same-clip correspondence survives destruction of temporal ordering and movement while future-coordinate skill disappears, the correspondence statistic is mainly a clip-recognition control. Passing this control cannot be advertised as future forecasting or general temporal understanding. Time reversal alone is not a falsifier for the historical speed-magnitude ratio because that target is reversal invariant.

### P1. Treat pseudo-depth, body scale and augmentation as measurement assumptions

**Evidence.** Paper v9 documents image-normalized x/y and crop-scaled inferred depth, rather than calibrated 3D positions. [geometry.py](../neurips-laterality/laterality/geometry.py), lines 110–150, divides by median shoulder/hip width with a fallback of 1. The encoder uses a clip-median pelvis fallback for missing hips; the target does not. [model.py](../neurips-laterality/laterality/model.py), lines 274–288, rotates the **x–z plane**, mixing image x and inferred depth, then translates x/y. This is a 3D-like augmentation of nonmetric coordinates, not simply an image-plane rotation.

**Repair.** Define coordinate units explicitly and compare image-plane 2D, image-plane coordinates converted to consistent pixel aspect ratio and body scale, and pseudo-3D channels as separate arms. Preserve original frame dimensions and crop transforms. Quantify confidence, missingness, left/right identity switches, bone-length instability and tracking jumps by source and viewpoint. Verify augmentation plausibility on training examples. Use a robust scale with a meaningful minimum-support gate; do not silently regard fallback scale 1 as a physical measurement. For future targets use prefix-estimated normalization only.

**Falsifier.** If a claimed movement gain disappears when inferred depth is removed or source/view/quality strata are held out, report that dependence. If stronger pose extraction or confidence handling explains the gain, identify it as a measurement improvement rather than attributing it solely to JEPA.

### P1. Keep symmetry a useful constraint, not the sole success criterion

**Evidence.** The supplied anatomical reflection swaps joint IDs and negates x. [evaluation.py](../neurips-laterality/laterality/evaluation.py), lines 334–446, explicitly constructs odd/even features from two passes. Zero-intercept odd readouts are odd by construction. [symmetry_learning.py](../neurips-laterality/laterality_extensions/symmetry_learning.py), lines 111–146, adds an identity-channel token-equivariance loss; a constant nonzero representation can satisfy it. The original strict diagnostic tests one specified latent channel action, not every possible equivariant representation.

**Repair.** Retain native single-pass, two-pass constructed, and matched-initial controls. If pursuing equivariance, separate invariant/global and signed/asymmetric feature components and evaluate useful endpoint prediction for each. A learned orthogonal involutive reflection map is an optional diagnostic fitted on training sources only, with mismatched-pair controls and the original strict test preserved. Avoid a blanket reflection-invariant pooled feature when the desired output changes sign under anatomical exchange.

**Falsifier.** Lower symmetry error with no future/readout improvement is a constraint trade-off, not scientific success by itself. If exact oddness appears equally with initialized encoders, it is evidence of the construction. Never describe a supplied joint schema or supervised fitted reflection map as symmetry discovered from unstructured video.

### P0 for forecasting. Reuse the existing prefix boundary but validate the entire full-video path

**Evidence.** [forecasting.py](../neurips-laterality/laterality_extensions/forecasting.py), lines 99–136, slices the observed prefix before computing origin, scale and causal last-observation sampling. Original observation times are input channels. Future supervision uses that frozen prefix coordinate frame. [future_comparison.py](../neurips-laterality/laterality_extensions/future_comparison.py), lines 82–106, keeps the same prefix eligibility and geometry for 12- versus 33-joint input comparisons. These are strong foundations. The tutorials use one fixed boundary per clip and short synthetic models; real forecast results are absent. Retained feasibility counts of 611 clips and 1,814 clip/horizon examples from 93 sources concern eligibility only.

**Repair.** On full walking sequences sample multiple boundaries after grouping sources, with a declared source/bout/window sampler. Predictions must depend only on past coordinates, past visibility, past timestamps, allowed metadata and a declared query horizon. Future visibility can determine scoring support after inference, but not queries, mask budgets, normalization or batching-dependent model inputs. Forecast evaluation should report common observed endpoints, horizon tolerance, actual timestamp offsets, track/bout attrition and uncertainty. Treat direct predicted-latent decoding, context-encoder readout and autoregressive rollout as separate experiments.

**Falsifier.** Append or replace future frames, future poses, confidence/visibility, bounding boxes and duration while holding the prefix fixed; require exactly unchanged prefix tensors, normalization, masks, query schedule and deterministic predictions. Include tests that catch full-clip smoothing, bidirectional tracking/preparation and endpoint-dependent input construction. Moving a timestamp across the boundary changes the available past and is not the invariance condition. Missing future observations should make an endpoint unscorable, not change the forecast.

### P0. Preserve per-example evidence and report the uncertainty actually estimated

**Evidence.** [comparative_evaluation.py](../neurips-laterality/laterality_extensions/comparative_evaluation.py), lines 868–937, jointly resamples sources across conditions and seeds and calculates paired seed-specific score differences. This respects source clustering conditional on fitted models. It does not refit encoders/readouts, create new splits, undo development selection or make reused seeds/cohorts independent.

**Repair.** Every full-sequence run should retain privately: exact manifest and grouping IDs, split roles, sampled time windows, preprocessing/config/code/environment hashes, all checkpoint states needed for replay, optimizer/RNG state for resume, per-window/per-horizon predictions and observed masks, train/validation selection tables, and complete source-weighted aggregate code. Keep `artifact_status` distinct from `scientific_result_status`; complete code execution can produce a null result. Declare one primary endpoint/contrast and label secondary comparisons exploratory or adjust the specified family. Show source-level effects and seed variation separately; use repeated group splits or retraining uncertainty only when actually run.

**Falsifier.** A machine should rebuild every paper number from retained predictions and a frozen analysis script without reading copied notebook display text. Deleting a source or duplicating its windows should trigger coverage checks or preserve the declared equal-source estimand as appropriate. If the raw evidence is unavailable, report aggregate-only provenance explicitly and do not claim an inference or bootstrap replay.

## 4. Implementation strengths to retain

1. Source-group inheritance, source-balanced training and source-balanced pooled metrics substantially improve on random clip splits.
2. Target calculations exclude invalid sentinels, require bilateral common support, and verify mirror behavior; natural missingness is distinguished from hidden training targets.
3. The paired mask runner fixes initialization, source draws, views, hidden counts and update exposure, and checks those properties. Ragged targets are reduced per clip, preventing high-support clips from silently receiving more loss weight.
4. Teacher gradients are prohibited, EMA and loss reductions stay FP32 under BF16, checkpoint identity includes scientific dependencies, and resume operates at shared-arm boundaries.
5. The original evaluation distinguishes constructed oddness from native behavior, uses matched initial models, and includes nuisance and incremental learned-plus-nuisance controls.
6. The forecasting helpers already implement a defensible prefix-based preparation contract and adversarial future mutation tests. Full-sequence experiments should extend this boundary rather than adapting the noncausal 64-frame preparation function into a forecast implicitly.
7. The latest paper v9 is appropriately narrow: a small skeleton study, source-held-out development evidence, no clinical validation and no real future forecasting. Preserve that candor while improving the experiment.

## 5. Recommended order of work

First implement a manifest-driven full-sequence preparation and evidence contract, preserving the historical experiment unchanged. Audit timing, tracking, coordinate geometry and source groups; establish a timestamp-aware direct-pose and matched-initial baseline on fixed observable endpoints. Then run the smallest readout and objective comparisons that can separate competing explanations. Only after a reproducible trained-over-initial benefit appears should mask/architecture scaling or symmetry-specific variants receive a larger grid. A rigorous explanation of a persistent negative result remains scientifically useful if it survives these controls; positive results must not be promised or obtained through repeated outer-test selection.

This document's recommendations are hypotheses and implementation requirements. They are not newly observed results, validated clinical measurements, or a claim that any proposed hyperparameter will necessarily improve R².
