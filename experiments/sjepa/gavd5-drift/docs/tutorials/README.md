# Tutorials

- [S-JEPA gait model internals](sjepa_model_internals.md): a step-by-step guide to the patch encoder, predictor, student-teacher wrapper, masking, objectives, training state, and downstream pooling.

The SVG source is generated by `make_class_figures.py` and stored in `figures/`.

The result examples in the tutorial follow the current 626-sequence GAVD-only run. “Augmented view” inside the model means a geometric transformation of a pose tensor; it does not mean that the retired added-normal dataset is enabled.
